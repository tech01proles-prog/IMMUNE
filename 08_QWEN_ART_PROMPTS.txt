# Immune Empire: Internal Front — Qwen Image 3.0 Art Prompt Pack
# File: 08_QWEN_ART_PROMPTS.txt

Purpose:
- Generate a coherent visual set for an incremental immune-system game using Qwen Image 3.0.
- Optimized for a solo developer with limited drawing skills.
- Focus on icons, cards, UI elements, abstract biology, and readable game assets.
- Avoid complex character animation, faces, hands, or crowded scenes.

Important:
- Check the current Qwen Image 3.0 license and platform policy before commercial use.
- On itch.io / CrazyGames, disclose AI-assisted art if required by platform or model terms.
- Use prompts mainly in English because image models often respond better to English tags.
- Generate many candidates, then select the best 20–30% and unify them in post-processing.

---

# 1. Global Style Guide

## Core visual direction

Stylized biomedical sci-fi / bioluminescent flat illustration.

The game should feel like:
- living microscopic world;
- clean but alien;
- not horror medicine;
- not cartoon childish;
- readable at small icon size;
- beautiful as cards and UI symbols.

## Mood keywords

bioluminescent, cellular, organic machinery, immune civilization, microscopic fortress, elegant biology, glowing tissues, speculative medical sci-fi, calm danger, living architecture.

## Shape language

- rounded organic forms;
- membrane curves;
- nucleus circles;
- spike proteins;
- filament strands;
- capsule shells;
- signal waves;
- soft particles;
- clear silhouettes.

## Avoid

- realistic gore;
- bloody wounds;
- detailed human faces;
- complex hands;
- too many tiny details;
- text inside images;
- logos;
- watermarks;
- cluttered backgrounds;
- photorealistic medical photos;
- overly cute anthropomorphic cells with eyes unless used as a special cosmetic style.

# 15. Animation Strategy Without Complex Art

Do not ask AI to generate perfect frame-by-frame animations. Instead generate static assets and animate in Godot.

## Safe animations

- pulse scale: 1.0 to 1.05;
- glow opacity oscillation;
- rotation of outer ring;
- particle emission;
- shader outline flicker;
- floating offset with sin();
- infection marker breathing;
- cell icons drifting slightly.

## Prompt for optional sprite sheet

Use only if you accept inconsistency.

Prompt:

simple 8-frame sprite sheet of a neutrophil immune cell floating, cyan white, flat vector, consistent size, transparent background, minimal motion, loop animation, no text, no watermark

Negative:

text, changing design, multiple rows, perspective change, realistic photo

Better approach:

Generate one clean cell icon, then animate in Godot with:
- Tween;
- shader;
- CPUParticles2D;
- small rotation/scale/position offsets.

# 16. Post-Processing Pipeline

After generating images:

1. Select best candidates.
2. Remove white background if icon.
3. Crop to square with padding.
4. Normalize brightness.
5. Apply shared palette map.
6. Add shared outline shader or stroke.
7. Add subtle noise/grain.
8. Export as PNG with transparency.
9. Import into Godot with correct compression.

## Shared look targets

- outline thickness similar;
- saturation similar;
- glow intensity similar;
- subject centered;
- background removed;
- no embedded text;
- consistent icon padding.

## Godot shader ideas

- outline pass;
- color tint by category;
- rim glow;
- scanline/noise overlay;
- desaturate locked assets;
- pulse shader for active infections.

- readable UI text inside images;
- logos or brand-like icons;

- photorealistic viruses/bacteria;
- too many small objects in one icon.

- one subject;
- clear silhouette;
- simple background;
- icon/card format;

# 25. Final Prompt Quality Checklist

Before accepting an generated image, check:

- Is the silhouette readable at 64x64?
- Does it fit the palette?
- Is there no accidental text?
- Is the background removable?
- Is it not too realistic/gory?
- Is it distinct from similar assets?
- Can it be tinted by category?
- Does it look okay on dark UI?
- Does it look okay on light tooltip background?
- Can it be animated with simple pulse/glow?

If an image fails readability, regenerate simpler.
