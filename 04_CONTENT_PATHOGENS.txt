# Immune Empire: Internal Front — Content Tables Part 3
# Pathogens, Threats, Beneficial Organisms

## Legend / Уровни контента

T0 = Tutorial: первые 1–3 минуты.
T1 = MVP: первые 15–30 минут, полный базовый цикл и первый престиж.
T2 = Alpha: 1–3 часа, углубление веток, воспаление, память, барьеры.
T3 = Beta: несколько дней, разные хозяева, вакцины, специализированные войны.
T4 = Endgame / Live: долгая игра, синтетический иммунитет, фаги, нейро-контроль, редкие угрозы.

## Format

id / Display Name | Tier | Type | Stats | Weakness | Resistance | Reward | Notes

Stats:
- Для живых патогенов: growth/s, resistance, threshold.
- Для токсинов и неживых угроз: damage/s, threshold.
- Boss / Major: усиленная версия, обычно требует специализации.

Weakness:
- Какие клетки, ресурсы или технологии эффективны против угрозы.

Resistance:
- Что снижает эффективность игрока или какие обычные ответы работают плохо.

Reward:
- Что игрок получает после победы/нейтрализации.

# 9. Suggested MVP Pathogen Set

For the first playable vertical slice, use only these:

1. swarm_coccus — basic bacteria.
2. shell_variant — basic virus.
3. thread_bloom — basic fungus.
4. metabolic_waste — basic toxin/detox pressure.
5. altered_self_cell — early surveillance tease.
6. commensal_bacteria — beneficial ecology tease.

This gives the player five clear lessons:

- bacteria: mass innate defense.
- viruses: NK/adaptive cellular defense.
- fungi: sustained macrophage/neutrophil pressure.
- toxins: liver/detox/antibodies.
- altered self: surveillance.
- commensals: not all microbes are enemies.

# 10. Difficulty Curve Notes

## T0 threats

Should be beatable with 5–15 neutrophils and one basic organ economy.

Goal: teach infection bar and resource cost.

## T1 threats

Should require mixing neutrophils and macrophages, or early NK for viruses.

Goal: teach specialization.

## T2 threats

Should require one of:

- dendritic/lymph node progression;
- barrier investment;
- microbiome management;
- inflammation control.

Goal: teach branching build.

## T3 threats

Should punish monoculture and neglect of tolerance/energy.

Goal: teach long-term balance.

## T4 threats

Should require multiple systems working together:

- memory;
- vaccines;
- engineered cells;
- organ map;
- host control;
- phage/symbiote ecology.

Goal: make the immune empire feel like a civilization, not a clicker.
