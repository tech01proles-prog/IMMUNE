## Legend / Уровни контента

T0 = Tutorial: первые 1–3 минуты.
T1 = MVP: первые 15–30 минут, полный базовый цикл и первый престиж.
T2 = Alpha: 1–3 часа, углубление веток, воспаление, память, барьеры.
T3 = Beta: несколько дней, разные хозяева, вакцины, специализированные войны.
T4 = Endgame / Live: долгая игра, синтетический иммунитет, фаги, нейро-контроль, редкие угрозы.

## General Rules

- События хозяина должны создавать мягкие выборы, а не наказывать за отсутствие реакции.
- Для MVP достаточно 6–10 событий.
- События не должны ломать экономику: лучше кратковременные баффы/дебаффы.
- Типы хозяев открываются через престиж и дают реиграбельность.
- Вакцины — постоянные бонусы внутри забега и/или после престижа.
- Мета-улучшения покупаются за иммунную память.
- Достижения нужны для удержания и ощущения коллекционирования.

# 7. Prestige / Meta Progression

## Prestige name

- New Host / Новый хозяин
- Ascend to New Host
- Generate Immune Epoch

## Prestige formula options

MVP simple:

- immune_memory = floor(total_antigens_collected / 50)

Better scaling:

- immune_memory = floor(sqrt(total_antigens_collected / 100))

Optional bonus:

- +10% memory for unique pathogen families cleared
- +25% memory for completing codex chapter
- -10% memory if run ended in severe autoimmune collapse, but still positive

## What resets

- resources
- organs/buildings
- cells/units
- active infections
- current-run technologies
- current inflammation/tolerance/barrier states
- temporary event buffs

## What persists

- immune_memory currency
- permanent upgrades
- codex entries
- vaccines if unlocked permanently
- discovered cell/pathogen types
- achievements
- cosmetics
- host archetype unlocks
- statistics

# 11. Event Scheduling Notes

## MVP event weights

For first 30 minutes:

- meal_protein: high
- meal_sugar: medium
- sleep_cycle: medium
- first bacterial outbreak: scripted or high weight
- first virus: after player has macrophage or 10 neutrophils
- fever_request: unlock after inflammation tech or first big outbreak
- stress_spike: low until T2

## Cooldowns

- Major negative events should have cooldowns.
- Do not stack two organ crises at once in MVP.
- Resource-positive events can be more frequent.
- Antibiotic event should not appear before microbiome_garden exists.

## Difficulty scaling

Event severity can scale by:

- total antigens collected
- run time
- host archetype
- prestige count
- current immune diversity

Example:

- pathogen_growth *= 1 + 0.02 * prestige_count
- pathogen_reward *= 1 + 0.05 * prestige_count

Keep rewards scaling slightly faster than difficulty to avoid frustration.
