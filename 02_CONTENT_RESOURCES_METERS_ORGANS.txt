# Immune Empire: Internal Front — Content Tables Part 1
# Resources, Meters, Organs / Buildings

## Legend / Уровни контента

T0 = Tutorial: первые 1–3 минуты.
T1 = MVP: первые 15–30 минут, полный базовый цикл и первый престиж.
T2 = Alpha: 1–3 часа, углубление веток, воспаление, память, барьеры.
T3 = Beta: несколько дней, разные хозяева, вакцины, специализированные войны.
T4 = Endgame / Live: долгая игра, синтетический иммунитет, фаги, нейро-контроль, редкие угрозы.

# 1. Resources

## 1.1. Primary Resources

- amino_acids / Аминокислоты
  Tier: T0
  Source: gut villi, diet events, protein digestion
  Sinks: cell creation, antibodies, enzymes, liver proteins
  Notes: базовый строительный материал для белков, рецепторов, ферментов и антител.

- glucose / Глюкоза
  Tier: T0
  Source: gut villi, glycogen breakdown, sugar events
  Sinks: ATP production, neutrophils, fever
  Notes: быстрое топливо для активных иммунных клеток.

- atp / АТФ
  Tier: T0
  Source: mitochondrial network, metabolism tech
  Sinks: cell upkeep, organ operation, division, movement
  Notes: универсальная клеточная энергия. Главный ограничитель армии.

- stem_cells / Стволовые клетки
  Tier: T0
  Source: bone marrow
  Sinks: training all leukocytes
  Notes: сырьё для производства лейкоцитов. Фактически лимит роста армии.

- lipids / Липиды
  Tier: T1
  Source: gut, liver, adipose tissue, microbiome events
  Sinks: macrophages, membranes, barriers, mast cells
  Notes: структурный ресурс для мембран, крупных клеток и барьеров.

- micronutrients / Микронутриенты
  Tier: T1
  Source: liver, diet, microbiome, sun/events
  Sinks: cell quality, enzyme cofactors, regulation
  Notes: витамины и минералы, сгруппированные в один ранний ресурс.

- antigens / Антигены
  Tier: T1
  Source: defeated pathogens, dendritic sampling, scans
  Sinks: adaptive immunity, vaccines, codex, memory
  Notes: фрагменты врагов. Ресурс знания, памяти и мета-прогресса.

## 1.2. Secondary Resources

- cytokines / Цитокины
  Tier: T2
  Source: activated immune cells, inflammation events
  Sinks: coordination, tech unlocks, fever, activation
  Notes: сигнальные молекулы. Усиливают иммунитет, но повышают риск шторма.

- nucleotides / Нуклеотиды
  Tier: T2
  Source: liver, diet, rapid cell turnover

  Sinks: bacterial lysis, opsonization, inflammation amplification
  Notes: белковый каскад. Усиливает уничтожение бактерий и标记 для фагоцитов.

- interferon / Интерферон

- microbiome_metabolites / Метаболиты микробиома

- hormones / Гормоны

- zinc / Цинк

  Source: diet, microbiome, mucosal turnover
  Sinks: antiviral enzymes, T-cell function, barrier integrity

- selenium / Селен

  Sinks: antioxidant defense, immune regulation

  Sinks: targeted antibacterial attacks, microbiome engineering
  Notes: полезные вирусы, охотящиеся на бактерии.

# 2. State Meters

- inflammation / Воспаление
  Range: 0–100+
  Increases: active innate cells, cytokines, fever, tissue damage
  Decreases: resolution tech, Treg, M2 macrophages, rest
  Effects: +defense, +cell speed, -tissue efficiency, +autoimmune risk.

- tolerance / Толерантность
  Range: 0–100
  Increases: Treg, resolution, microbiome metabolites, calm host
  Decreases: high inflammation, repeated false alarms
  Effects: -autoimmune risk, stabilizes organs, may reduce peak aggression.

- barrier_integrity / Барьерная целостность
  Range: 0–100
  Increases: skin, mucosa, tight junctions, vitamins, microbiome
  Decreases: pathogen enzymes, toxins, stress, inflammation
  Effects: reduces pathogen entry and toxin leakage.

- energy_balance / Энергетический баланс
  Range: -100–100
  Increases: ATP surplus
  Decreases: ATP deficit, fever, dense army
  Effects: modifies cell speed and organ output.

- immune_diversity / Разнообразие иммунитета
  Range: 0–100
  Increases: many active cell types, balanced tech
  Decreases: spamming one unit type
  Effects: reduces pathogen adaptation, grants stability bonus.

- immune_memory / Иммунная память
  Range: 0+
  Increases: defeated pathogens, vaccines, codex
  Decreases: usually not spent directly
  Effects: bonuses vs known pathogens, prestige currency.

- stress / Стресс хозяина
  Range: 0–100
  Increases: host events, lack of sleep, pain, overload
  Decreases: sleep, calm, neuro-immune tech
  Effects: suppresses some immunity, increases cortisol effects.

- sleep_quality / Качество сна
  Range: 0–100
  Increases: rest events, melatonin, low stress
  Decreases: host activity, fever, stress
  Effects: improves memory consolidation and repair.

# 3. Organs / Buildings

## 3.1. General Cost Pattern

cost(n) = base_cost * growth^n

Рекомендуемые growth:
- T0 extractors: 1.15
- T0/T1 energy and marrow: 1.17–1.20
- T1 refineries/training: 1.18–1.25
- T2 powerful organs: 1.22–1.30
- T3/T4 endgame organs: 1.30–1.40
