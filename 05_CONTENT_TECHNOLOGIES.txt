## Legend / Уровни контента

T0 = Tutorial: первые 1–3 минуты.
T1 = MVP: первые 15–30 минут, полный базовый цикл и первый престиж.
T2 = Alpha: 1–3 часа, углубление веток, воспаление, память, барьеры.
T3 = Beta: несколько дней, разные хозяева, вакцины, специализированные войны.
T4 = Endgame / Live: долгая игра, синтетический иммунитет, фаги, нейро-контроль, редкие угрозы.

## General Tech Rules

- Технологии в этом файле относятся к текущему забегу.
- Постоянные мета-улучшения после престижа описаны отдельно.
- Стоимость базовая, её можно масштабировать по прогрессу забега.
- Требования для MVP лучше делать простыми: OR минимален, AND только для ключевых разблокировок.
- Игрок должен иметь возможность развивать любую ветку, но узкие билды имеют сильные стороны и явные дыры.

# 11. Tech Web Connection Notes

## Recommended starter choices

Для первых 10 минут игрок должен видеть не все технологии, а 3–5 доступных:

- chemotaxis_1
- glycolytic_flux
- antigen_presentation_1 или oxidative_burst_1
- mucus_production
- anti_inflammatory_signals

Остальное открывается по мере появления органов, клеток и типов угроз.

## Soft counter system

Технологии не должны быть обязательными для прохождения. Лучше сделать мягкие контр-связи:

- бактерии: проще через innate swarm, complement, neutrophil/macrophage.
- вирусы: проще через NK, interferon, cytotoxic T, memory T.
- грибки: проще через macrophage, neutrophil, Th17, antifungal peptides.
- паразиты: проще через eosinophil, mast cell, Th2, IgE.
- токсины: проще через antibodies, detox, liver.
- аутоиммунность: проще через Treg, resolution, tolerance.
- изменённые клетки: проще через NK, CTL, immune surveillance, CAR-T.

## Diversity bonus

Хорошая базовая формула для поздней игры:

diversity_bonus = 1 + 0.02 * unique_active_cell_types

Но лучше ограничивать и делать нелинейно, чтобы игрок не собирал по одной клетке всех типов без смысла.

Например:

diversity_bonus = 1 + min(0.30, 0.03 * unique_active_cell_types)

## Specialist penalty

Если игрок использует только один тип клеток против патогена, который к нему адаптирован:

adaptation_penalty = 0.60–0.85

Если использует 3+ подходящих типа:

adaptation_penalty = 1.00

Это делает разнообразие ценным, но не обязательным до боли.
