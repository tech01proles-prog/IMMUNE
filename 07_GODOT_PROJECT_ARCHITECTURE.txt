# Immune Empire: Internal Front — Godot Project Architecture
# File: 07_GODOT_PROJECT_ARCHITECTURE.txt

Target:
- Godot 4.x, preferably 4.3+
- PC + Web export
- itch.io HTML5
- CrazyGames web build
- incremental / idle simulation
- one developer, limited art, data-driven design

Core principles:
1. Data-driven content.
   All organs, cells, pathogens, technologies, events, vaccines, hosts and meta upgrades should live in JSON or Godot Resources, not hardcoded in scenes.

2. Simulation separated from UI.
   Game logic must not depend on nodes being visible. UI only reads state and sends commands.

3. Fixed-step simulation.
   Use an accumulator and simulate in stable steps. This makes offline progress, balancing and debugging easier.

4. Web-friendly performance.
   Do not create thousands of nodes for cells. Use numbers for logic and a small visual pool for feedback.

5. Versioned saves.
   Always include save version and migration path. Incremental games live for months or years.

6. Soft failure.
   No game over in MVP. Bad balance should cause setbacks, debuffs, autoimmune flares, resource loss, but not permanent death.

# 3. Data Flow

High-level flow:

1. Definitions loads all JSON content at startup.
2. GameState holds current run state and meta state.
3. Simulation runs fixed steps and mutates GameState.
4. Systems read Definitions and GameState, write derived values back into GameState.
5. UI polls GameState or listens to SignalBus, throttled to 5–10 updates per second.
6. SaveManager serializes GameState, not derived cache values.
7. OfflineSystem simulates elapsed time when game loads.
8. PlatformBridge handles web-specific behavior, ads, pause/resume, storage fallback.

Important rule:
Do not store calculated values like “total defense” or “income per second” in the save unless needed for debugging. Recalculate them from base state.

Useful helper functions:

func has_resource_enough(cost: Dictionary) -> bool:
    for id in cost.keys():
        if resources.get(id, 0.0) < float(cost[id]):
            return false
    return true

func spend_cost(cost: Dictionary) -> bool:
    if not has_resource_enough(cost):
        return false
    for id in cost.keys():
        resources[id] -= float(cost[id])
    return true

func add_resource(id: String, amount: float) -> void:
    if not resources.has(id):
        resources[id] = 0.0
    resources[id] += amount
    if resources[id] < 0.0:
        resources[id] = 0.0

func get_organ_level(id: String) -> int:
    return int(organs.get(id, 0))

func get_cell_count(id: String) -> int:
    return int(cells.get(id, 0))

func has_tech(id: String) -> bool:
    return bool(techs.get(id, false))

# 5. Definitions Loader

Definitions.gd loads JSON content and validates it.

extends Node

var resources := {}
var organs := {}
var cells := {}
var pathogens := {}
var pathogen_modifiers := {}
var techs := {}
var events := {}
var hosts := {}
var doctrines := {}
var vaccines := {}
var meta_upgrades := {}
var achievements := {}
var journal_messages := {}
var balance := {}

func _ready() -> void:
    load_all()
    validate_all()

func load_all() -> void:
    resources = load_json("res://data/resources.json")
    organs = load_json("res://data/organs.json")
    cells = load_json("res://data/cells.json")
    pathogens = load_json("res://data/pathogens.json")
    pathogen_modifiers = load_json("res://data/pathogen_modifiers.json")
    techs = load_json("res://data/techs.json")
    events = load_json("res://data/events.json")
    hosts = load_json("res://data/hosts.json")
    doctrines = load_json("res://data/doctrines.json")
    vaccines = load_json("res://data/vaccines.json")
    meta_upgrades = load_json("res://data/meta_upgrades.json")
    achievements = load_json("res://data/achievements.json")
    journal_messages = load_json("res://data/journal_messages.json")
    balance = load_json("res://data/balance_constants.json")

func load_json(path: String) -> Dictionary:
    var file := FileAccess.open(path, FileAccess.READ)
    if file == null:
        push_error("Cannot open %s" % path)
        return {}
    var text := file.get_as_text()
    var parsed = JSON.parse_string(text)
    if typeof(parsed) != TYPE_DICTIONARY:
        push_error("Invalid JSON dictionary in %s" % path)
        return {}
    return parsed

func validate_all() -> void:
    validate_collection(resources, "resource")
    validate_collection(organs, "organ")
    validate_collection(cells, "cell")
    validate_collection(pathogens, "pathogen")
    validate_collection(techs, "tech")

func validate_collection(dict: Dictionary, type_name: String) -> void:
    for id in dict.keys():
        var def: Dictionary = dict[id]
        if not def.has("id"):
            push_warning("%s %s missing id field" % [type_name, id])
        elif def.id != id:
            push_warning("%s %s id mismatch: %s" % [type_name, id, def.id])

# 7. Simulation Architecture

Use a dedicated Simulation node as root of gameplay scene or autoload.

Recommended:
- Main.tscn contains Simulation node.
- Simulation calls systems in fixed order.
- Systems are plain RefCounted objects or Node children.

Simulation.gd skeleton:

extends Node

const FIXED_STEP := 0.1 # 10 Hz logic
const UI_UPDATE_INTERVAL := 0.2 # 5 Hz UI

var accumulator := 0.0
var ui_timer := 0.0

@onready var production := $ProductionSystem
@onready var defense := $DefenseSystem
@onready var infection := $InfectionSystem
@onready var status := $StatusSystem
@onready var events := $EventRunner
@onready var achievements := $AchievementSystem

func _process(delta: float) -> void:
    if get_tree().paused:
        return

    accumulator += delta

    var max_steps := 20
    var steps := 0
    while accumulator >= FIXED_STEP and steps < max_steps:
        step_simulation(FIXED_STEP)
        accumulator -= FIXED_STEP
        steps += 1

    if steps >= max_steps:
        accumulator = 0.0

    ui_timer += delta
    if ui_timer >= UI_UPDATE_INTERVAL:
        ui_timer = 0.0
        SignalBus.state_tick.emit()

func step_simulation(dt: float) -> void:
    GameState.stats.playtime_seconds += dt

    production.tick(dt)
    defense.recompute()
    infection.tick(dt)
    status.tick(dt)
    events.tick(dt)
    achievements.tick(dt)

Why fixed step:
- stable resource math
- easier offline simulation
- less FPS-dependent bugs
- predictable infection growth

For idle games, 10 Hz logic is usually enough. Visual animation can run at render FPS.

# 8. ProductionSystem

Responsibilities:
- calculate resource income
- calculate resource consumption
- apply organ levels and tech multipliers
- handle bottlenecks like ATP or stem cells

Basic algorithm:

1. Start with zero rates.
2. For each owned organ:
   - add base output * level
   - subtract base consumption * level
3. Apply tech/resource multipliers.
4. Apply global meta multipliers.
5. If consumption exceeds available income, reduce efficiency of dependent systems.
6. Add net rates * dt to resources.

Pseudo-code:

func tick(dt: float) -> void:
    var rates := {}
    var consumption := {}

    for organ_id in GameState.organs.keys():
        var level := int(GameState.organs[organ_id])
        if level <= 0:
            continue
        var def := Definitions.organs[organ_id]
        for res_id in def.output.keys():
            rates[res_id] = rates.get(res_id, 0.0) + float(def.output[res_id]) * level
        for res_id in def.consumption.keys():
            consumption[res_id] = consumption.get(res_id, 0.0) + float(def.consumption[res_id]) * level

    apply_tech_resource_multipliers(rates)
    apply_meta_multipliers(rates)

    for res_id in rates.keys():
        GameState.resources[res_id] = GameState.resources.get(res_id, 0.0) + rates[res_id] * dt

    for res_id in consumption.keys():
        var needed := consumption[res_id] * dt
        if GameState.resources[res_id] >= needed:
            GameState.resources[res_id] -= needed
        else:
            GameState.resources[res_id] = 0.0
            GameState.meters.energy_balance -= 1.0

Store rates in GameState or a derived cache for UI:

GameState.derived.resource_rates = rates
GameState.derived.atp_deficit = ...

Do not save derived cache.

# 9. DefenseSystem

Responsibilities:
- calculate total defense per pathogen type
- account for cell counts, techs, ATP efficiency, inflammation, memory, diversity, host modifiers

Defense formula:

total_defense(pathogen_type) =
    base_cell_defense
    * atp_efficiency
    * inflammation_multiplier
    * memory_multiplier
    * diversity_multiplier
    * tech_multipliers
    * host_multipliers
    * event_multipliers

Base cell defense:

for each cell_id:
    count = GameState.cells[cell_id]
    defense_value = Definitions.cells[cell_id].defense[pathogen_type]
    total += count * defense_value

ATP efficiency:

required_upkeep = sum(cell_count * cell.upkeep.atp)
atp_income = derived.atp_rate
if required_upkeep <= 0:
    efficiency = 1.0
else:
    efficiency = clamp(atp_income / required_upkeep, 0.25, 1.0)

If ATP is deficient, cells do not die immediately. They become slower/less effective. This is gentler for idle.

Inflammation multiplier:

innate_bonus = 1.0 + clamp(GameState.meters.inflammation * 0.004, 0.0, 0.6)
adaptive_penalty = 1.0 - clamp(GameState.meters.inflammation * 0.001, 0.0, 0.15)

Use innate_bonus for innate cells, adaptive_penalty or neutral for adaptive cells.

Memory multiplier:

if pathogen is known:
    memory_bonus = 1.0 + min(0.5, codex_entry.memory_level * 0.05)
else:
    memory_bonus = 1.0

Diversity multiplier:

unique_active_cell_types = count cells with count > 0
diversity_bonus = 1.0 + min(0.30, unique_active_cell_types * 0.03)

Store results:

GameState.derived.defense_by_type = {
    "bacteria": ...,
    "viruses": ...,
    "fungi": ...,
    "parasites": ...,
    "toxins": ...,
    "altered_self": ...
}

# 10. InfectionSystem

Active infection object structure:

{
  "uid": 12,
  "pathogen_id": "swarm_coccus",
  "sector": "blood",
  "load": 8.4,
  "growth": 0.15,
  "resistance": 2.0,
  "threshold": 25.0,
  "elapsed": 12.3,
  "modifiers": ["rapid_growth"],
  "symptom_active": false
}

Tick algorithm:

for infection in active_infections:
    def = Definitions.pathogens[infection.pathogen_id]
    ptype = def.type
    defense = GameState.derived.defense_by_type.get(ptype, 0.0)
    resistance = infection.resistance * get_modifier_resistance(infection)

    suppression = defense / (defense + resistance)
    suppression = clamp(suppression, 0.0, 0.99)

    growth = infection.growth * get_growth_multiplier(infection)
    clearance = def.clearance_base * suppression

    infection.load += growth * (1.0 - suppression) * dt
    infection.load -= clearance * dt
    infection.load = max(infection.load, 0.0)
    infection.elapsed += dt

    if infection.load >= infection.threshold and not infection.symptom_active:
        activate_symptom(infection)

    if infection.load <= 0.0:
        clear_infection(infection)

Important:
Do not let suppression reach exactly 1.0 too easily. Use defense / (defense + resistance) so growth never fully stops unless defense is extremely high. This keeps tension.

Clear infection:

- remove from active_infections
- add rewards
- update codex
- increase immune memory stat
- emit SignalBus.infection_cleared
- maybe spawn antigen resource
- increment stats.outbreaks_cleared

Symptom activation:

- apply temporary debuff to sector organ
- increase inflammation
- reduce production by 10–30%
- add journal warning
- do not destroy save

Pathogen spawning:

Use EventManager or InfectionScheduler.

Simple MVP scheduler:

- first infection scripted after 30–60 seconds
- then random every 60–180 seconds
- choose pathogen tier based on player progress
- avoid same type too often
- respect host archetype and sector unlocks

Weighted selection example:

weight = base_weight
if player has weak defense vs type:
    weight *= 1.2
if player recently fought same type:
    weight *= 0.6
if pathogen tier > current allowed tier:
    weight = 0

# 11. StatusSystem

Updates meters:

- inflammation
- tolerance
- barrier_integrity
- energy_balance
- immune_diversity
- stress
- sleep_quality

Each meter has base drift, sources and sinks.

Example inflammation:

inflammation_gain = 0
for cell_id in cells:
    inflammation_gain += cell_count * cell.inflammation_per_second
inflammation_gain *= tech_inflammation_mult
inflammation_gain += event_inflammation_delta

inflammation_decay = balance.inflammation_decay_base
inflammation_decay += tolerance * 0.001
inflammation_decay += resolution_tech_bonus

GameState.meters.inflammation += (inflammation_gain - inflammation_decay) * dt
clamp 0..100+

Tolerance:

tolerance_gain = treg_count * 0.01 + microbiome_bonus + rest_bonus
tolerance_decay = inflammation * 0.002 + stress * 0.001

Barrier integrity:

gain from skin/mucosa organs, vitamins, repair tech
decay from pathogens with barrier_breaker, toxins, inflammation

Energy balance:

energy_balance = atp_income - atp_upkeep
normalize to -100..100 for UI, but internal can be raw float.

Immune diversity:

count unique active cell categories or cell ids.
Can be smoothed over time to avoid flicker.

Stress/sleep:
- mostly event-driven in MVP
- later circadian rhythm and host actions

Status effects:
- high inflammation: +innate defense, -organ efficiency, +autoimmune risk
- low tolerance: chance of autoimmune flare
- low barrier: higher pathogen entry chance
- negative energy: cell efficiency penalty
- high stress: latent virus reactivation chance
- low sleep: memory consolidation penalty

Rebuild triggers:

func rebuild_modifiers() -> void:

EventManager handles:
- host events

Event runner tick:

Event triggers:

- instant resource bursts

# 14. OfflineSystem

Offline progress is essential for idle games.

On load:

1. Read last_save_time.
2. Compute offline_seconds = now - last_save_time.
3. Clamp to cap:
   - MVP: 8 hours
   - later: 24 hours
   - donation/ad could temporarily increase cap
4. Simulate in coarse steps.
5. Show summary popup.

Coarse simulation options:

Option A: simple analytic
- resources += net_rate * offline_seconds
- infections updated with average defense
- fast but less accurate

Option B: step simulation
- run step_simulation(60.0) for each minute
- cap iterations, e.g. 480 steps for 8 hours
- more accurate, still cheap

Recommended MVP:
- use 60-second steps
- max 480 steps
- disable expensive UI updates
- disable random events except scheduled ones
- process infections and resources
- consolidate memory based on sleep_quality

Offline summary data:

{
  "seconds": 14400,
  "resources_gained": {},
  "infections_cleared": 3,
  "infections_started": 2,
  "antigens_gained": 12,
  "memory_consolidated": 4,
  "damage_events": 1
}

Important:
If browser tab is hidden but game process still running, do not double-count offline time. Use either:
- pause logic and rely on real-time delta, or
- save timestamp on visibility change and compute offline on resume.

For web, safest:
- on visibility hidden: save timestamp, pause simulation
- on visibility visible: compute elapsed and run offline simulation

# 18. Number Formatting

Incremental games need readable large numbers.

utils/NumberFormat.gd:

static func format(value: float, decimals: int = 1) -> String:
    var abs_value := abs(value)
    if abs_value < 1000.0:
        return String.num(value, decimals)
    var suffixes := ["K", "M", "B", "T", "Qa", "Qi", "Sx", "Sp", "Oc", "No", "Dc"]
    var tier := int(floor(log(abs_value) / log(1000.0)))
    tier = clamp(tier, 1, suffixes.size())
    var scaled := value / pow(1000.0, tier)
    return String.num(scaled, decimals) + suffixes[tier - 1]

For very late game, consider scientific notation or custom suffix table.

UI should show:
- current amount
- net rate per second
- deficit warnings
- “can afford” highlighting

When systems need a value:

func get_cell_defense_mult(cell_id: String, against: String) -> float:
    var mods := GameState.derived.modifiers
    var base := 1.0
    base *= mods.global_income_mult
    base *= mods.cell_defense_mult.get(cell_id, {}).get(against, 1.0)
    base *= mods.cell_defense_mult.get(cell_id, {}).get("all", 1.0)
    return base

This makes tech effects data-driven and easy to balance.

# 22. PrestigeSystem

Prestige should be a clean reset with explicit persistence.

Available when:
- total_antigens_this_run >= threshold
- or cleared required outbreaks
- or reached organ/tech milestone

Preview memory gain:

func calculate_memory_gain() -> float:
    var base := floor(GameState.total_antigens_this_run / 50.0)
    var codex_bonus := 1.0 + min(0.5, GameState.codex.size() * 0.02)
    var diversity_bonus := 1.0 + min(0.25, get_unique_pathogen_families_cleared() * 0.05)
    return floor(base * codex_bonus * diversity_bonus)

Perform prestige:

1. Save meta values.
2. Add immune_memory.
3. Unlock hosts/doctrines if thresholds met.
4. Persist codex and vaccines if allowed.
5. Reset run state.
6. Apply meta starting bonuses.
7. Rebuild modifiers.
8. Emit prestige_completed.
9. Save immediately.

Do not reset:
- settings
- achievements
- codex
- meta currency
- permanent upgrades
- unlocked content

# 24. Web Export Settings

For Godot 4 web export:

- Use Release template.
- Disable debug collision/paths in final build.
- Keep export single executable? For web, use HTML5 export.
- Enable “Variant” with release only.
- Do not include unused plugins.
- Compress textures.
- Prefer SVG or small PNG icons.
- Use .ogg or .mp3 carefully; web support varies. OGG/Vorbis is usually okay, but test.
- Keep total build size modest, ideally under 30–60 MB for web, lower is better.
- For Godot 4, WebAssembly can be large. Use export options to strip unused classes if available.
- Test in Chrome/Firefox/Edge and mobile browser.

Project Settings suggestions:
- Rendering > Textures > Default Texture Filter: Canvas Items or Nearest for pixel-ish style
- Rendering > 2D > Snap Controls to Pixels: optional
- Application > Run > Low Processor Mode: can enable, but ensure idle logic still runs
- Engine > Max FPS: 60 or 30 for web
- Audio > Driver: depending on compatibility, default usually fine

For low-end web:
- visual_quality setting:
  - low: no particles, fewer animations, 30 fps
  - medium: limited particles
  - high: full effects

# 30. Common Pitfalls

Pitfall 1: Hardcoding content in scenes.
Fix: all ids come from JSON.

Pitfall 2: UI driving simulation.
Fix: simulation runs independently; UI is read-only.

Pitfall 3: Creating a node per cell.
Fix: logic uses counts, visuals use pool.

Pitfall 4: Saving derived values.
Fix: save base state only, rebuild derived on load.

Pitfall 5: No save version.
Fix: always include version and migration.

Pitfall 6: Offline double-counting.
Fix: pause on hidden, save timestamp, simulate once on resume.

Pitfall 7: Too many resources at start.
Fix: unlock resources gradually with organs and pathogens.

Pitfall 8: Inflammation only negative.
Fix: make it a powerful but risky multiplier.

Pitfall 9: Adaptive immunity too complex early.
Fix: show dendritic/lymph node only after first antigen need.

Pitfall 10: Web build too heavy.
Fix: small assets, release export, limited particles, optional quality settings.

# 32. Final Architecture Summary

Use this stack:

- Godot 4
- JSON data definitions
- Autoload singletons for state and services
- Fixed-step simulation
- Derived modifier cache
- UI throttled updates
- Object-pooled visuals
- Versioned JSON saves
- Offline coarse simulation
- PlatformBridge for web/SDK stubs
- Data-driven effects for techs, vaccines, hosts, meta upgrades

The most important technical decision:
Keep the game as a simulation of numbers and states first, visuals second.

If the core loop is fun with colored rectangles and text, it will become much better after adding Qwen-generated icons, particles, sound and polish.
